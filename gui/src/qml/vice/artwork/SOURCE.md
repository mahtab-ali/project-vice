# Artwork

The Vice UI shows `key-art.jpg` from this folder behind its screens when the
file is present, and a plain navy gradient when it is not.

`key-art.jpg` is not part of this repository and is not covered by the
source-code licence. The approved design uses the "Jason and Lucia 01"
wallpaper published by Rockstar Games at
https://www.rockstargames.com/VI/media/artwork-wallpapers. That artwork is
copyright Rockstar Games / Take-Two Interactive. Download it for your own
local build with `scripts/vice-fetch-artwork.sh`; do not redistribute it
without permission from the copyright holder.

Any 16:9 image saved here as `key-art.jpg` works. The crops each screen uses
are set in `components/Artwork.qml`.
