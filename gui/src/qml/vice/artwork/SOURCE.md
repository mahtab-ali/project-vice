# Artwork

The Vice UI shows `key-art.jpg` from this folder behind its screens, and a
plain navy gradient if the file is missing.

`key-art.jpg` is the "Jason and Lucia 01" wallpaper published by Rockstar
Games at https://www.rockstargames.com/VI/media/artwork-wallpapers, downloaded
unchanged on 19 November 2026. It is copyright Rockstar Games / Take-Two
Interactive. It is not covered by this project's source-code licence, and no
licence to redistribute it has been obtained. It is included at the project
owner's decision.

To use different artwork, replace the file with any 16:9 image of the same
name. The crop each screen uses is set where the screen declares its
`artwork`, and in `components/Artwork.qml`.
